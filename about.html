Introduction

The Web Based Blogging System is designed to allow users to register, log in, publish blog posts and view blog articles.

Objective

This is a basic project to demonstrate implementation of HTML, CSS, JAVASCRIPT, PHP for web technologies in one application.

Technologies Used

  • HTML for webpage structure
  • CSS for page styling
  • JavaScript for validation and alerts
  • PHP for backend processing
  • MySQL for database storage
